# Сайт ЛучЭкспо / RayExpo

Многостраничный сайт на чистом HTML/CSS/JS (RU + EN). Страницы собираются скриптом из текстов и папок с фото, на хостинг загружается готовая папка `dist/`. Заявки отправляет `send.php` на почту, без CRM.

## Сборка

```bash
npm install          # один раз
npm run build        # собрать сайт в dist/
npm run serve        # локальный просмотр: http://localhost:8080
```

## Как добавить фото проекта

1. Откройте папку направления в `content/photos/`:
   - `stendy/poluostrov`, `stendy/dvuhetazhnye`, `stendy/eksklyuzivnye`, `stendy/uglovye`, `stendy/ulichnye`, `stendy/s-ekranom`
   - `art/obemnye-figury`, `art/teatralnye-dekoracii`, `art/arhitekturnye-formy`, `art/novogodnee-oformlenie`, `art/oformlenie-tc`
2. Положите фото (jpg, png или webp). **Имя файла — это название проекта на сайте**, номер в начале задаёт порядок:
   `04 Стенд для выставки Иннопром.jpg`
3. Если у проекта несколько фото, создайте папку `04 Название проекта/` и сложите фото туда. Обложкой станет файл `обложка.jpg` или, если его нет, первый файл по алфавиту. При клике открывается галерея.
4. Английское название (по желанию) — в `en.json` той же папки: `{ "Стенд для выставки Иннопром": "Innoprom exhibition stand" }`.
5. Выполните `npm run build` и загрузите `dist/` на хостинг.

Фото автоматически сжимаются в WebP (480/960/1600 px) и подгружаются лениво.

## Где что менять

| Что | Файл |
|---|---|
| Телефоны, адрес, почта, часы, реквизиты, ID Метрики, код Вебмастера | `content/config.mjs` |
| Направления, услуги, цены, вопросы, отзывы, логотипы клиентов | `content/content.mjs` |
| SEO-заголовки и тексты страниц | `content/pages.mjs` |
| Статьи блога | `content/blog.mjs` |
| Почта для заявок (SMTP) | `static/mail-config.php` |

Новая услуга, например «Объёмные буквы», — это ещё один объект в массиве `services` в `content/content.mjs`. Страница, меню и карта сайта создадутся сами.

## Запуск на хостинге

1. Хостинг с PHP 8 и Apache (`.htaccess`): Beget, Timeweb и т. п. Домен `luchexpo.ru` (на 16.10.2026 свободен, `rayexpo.ru` занят).
2. Загрузите содержимое `dist/` в корень сайта и включите бесплатный SSL.
3. Почта: создайте ящик на Яндексе, включите «Пароль приложения» и впишите его в `mail-config.php` на сервере.
4. Яндекс Метрика: создайте счётчик, впишите номер в `metrikaId` и пересоберите сайт. В Метрике заведите цели типа «JavaScript-событие»:
   - `lead_form` — отправка заявки (основная цель);
   - `phone_click` — клик по телефону;
   - `open_form` — открытие формы заявки;
   - `email_click`, `portfolio_view` — дополнительные цели.
5. Яндекс Вебмастер: добавьте сайт, впишите код в `yandexVerification`, пересоберите, подтвердите права и отправьте `https://luchexpo.ru/sitemap.xml`.

## Что нужно получить от заказчика ([заполнить])

- почта для сайта и заявок; часы работы; мессенджеры;
- реальные отзывы клиентов (выдуманные не публикуем) и логотипы клиентов с разрешением на показ;
- номинал и условия подарочного сертификата;
- реальные фото проектов вместо AI-визуализаций; фото для пустых направлений (двухэтажные стенды, объёмные фигуры, театральные декорации, архитектурные формы).
